data: url generator

turns a link into a data: page with no domain for filters to catch — opens the site in a framed blank tab

about:blank launcher

loads any link inside a blank tab titled like ixl — the address bar just reads about:blank

raw html to data:

paste html and get a data: url that renders it — handy for saved pages or quick embeds

base64 encoder / decoder

encode a string to base64 or decode it back

url encoder / decoder

escape or unescape special characters in a link

tab disguise

instantly swap this tab's name and icon to blend in — tap one to apply
